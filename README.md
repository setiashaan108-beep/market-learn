
# Project Name - MarketLearn

## Project purpose
MarketLearn is an online course enrollment platform that facilitates seamless education workflows between three primary roles: Learners, Instructors, and Admins.

## Tech Stack
* **Frontend:** React + TypeScript
* **Build Tool:** Vite
* **State Management:** Redux Toolkit
* **Testing:** Vitest + React Testing Library
* **Formatting/Linting:** ESLint + Prettier 

## How to install
* git clone https://github.com/setiashaan108-beep/market-learn
* cd market-learn
* npm i

## How to run
npm run dev

## How to test
npm run test
